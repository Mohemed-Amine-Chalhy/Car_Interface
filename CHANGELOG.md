# Changelog

All notable changes to Car Interface are documented here. The project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- A typed, layered Python application under `src/car_interface` with simulation
  and physical-hardware adapters.
- Explicit `car_v1` and `school_car_legacy_v0` serial protocol profiles.
- Controller, RPLidar, command-dispatch, diagnostics, and desktop UI services.
- Unit, integration, regression, and opt-in hardware test suites.
- Locked `uv` environments, Ruff, strict mypy, Bandit, pre-commit hooks, and
  Windows/Linux CI.
- Reproducible Python packages and a smoke-tested Windows desktop bundle.
- Engineering documentation covering architecture, configuration, hardware,
  firmware, perception, testing, and release workflows.
- A project case study, reconstructed vehicle specification, and original
  system diagrams.

### Changed

- Reworked the original prototype into a maintainable application with bounded
  queues, explicit device lifecycles, structured state, and testable adapters.
- Made simulation the default development environment.
- Added explicit configuration for the historical car's steering calibration,
  command pacing, controller orientation, and serial protocol.

### Removed

- Standalone experimental scripts, IDE metadata, generated bytecode, notebook
  output, and the untracked historical model binary from the maintained tree.
