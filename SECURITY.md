# Security policy

## Supported versions

Security fixes are applied to `main` and, after releases begin, the latest
tagged release. Other commits and older releases are unsupported.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Latest tagged release | Yes |
| Other revisions | No |

## Report a vulnerability

Use a
[private GitHub security advisory](https://github.com/Mohemed-Amine-Chalhy/Car_Interface/security/advisories/new).
Do not open a public issue for a vulnerability before maintainers have reviewed
it.

Include the information needed to reproduce and assess the report:

- affected version or commit;
- operating system and Python version;
- concise expected and observed behavior;
- minimal reproduction or proof of concept;
- relevant configuration, protocol, firmware, and hardware versions;
- a short log excerpt or trace; and
- known workarounds or impact.

Remove credentials, usernames, private paths, USB serial numbers, and other
personal data before attaching logs. Use simulation for a reproduction when it
demonstrates the same issue.
